# Technical Documentation Assistant Using RAG

## Project Description

This project develops a Retrieval-Augmented Generation (RAG) chatbot that answers questions from Python technical documentation.

## Technologies Used

- Python
- Google Colab
- Sentence Transformers
- FAISS
- Gemini
- Gradio
- PyPDF

## Main Features

- Technical documentation knowledge base
- PDF text extraction
- Text chunking
- Semantic search
- Vector database
- RAG-based question answering
- Documentation references
- Prevention of unsupported answers

## Project Workflow

User Question
↓
Text Embedding
↓
Semantic Search
↓
Relevant Documentation
↓
Gemini
↓
Grounded Answer
